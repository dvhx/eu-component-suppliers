# eu-component-suppliers
Curated list of EU-based electronic component suppliers

Every shop on this list is physically located within the European Union,
meaning you avoid the new €3 per item customs tariff on non-EU imports.

The list is in this CSV file [suppliers.csv](suppliers.csv)

CSV Columns:

- url - url of the shop
- shipping - approximate shipping cost range (to home country, to other eu country)
- free_shipping - amount above which shipping is free
- country - home country (usually lower shipping cost and faster delivery)
- ships_to - eu means ships to eu, world means ships anywhere, otherwise comma separated list of ISO country codes
- last_updated - when was the record last updated
- notes - other notes

Feel free to expand the list (via issues or pull requests).
